## My role & impact
- Stabilized and grew organic search traffic on this legacy medical education site, driving a **114% increase in Google Search clicks** (impressions up 94%) following security, performance, and indexing fixes.
- Remediated a badly inherited server: replaced unlicensed plugin copies with legitimate licenses, removed leftover developer SSH keys and admin accounts, fixed world-readable permissions, and locked the origin down to the Sucuri firewall it had been silently bypassing.
- Upgraded PHP 8.0 → 8.3, cut active plugins from **33 to 25**, removed ~300MB of dead code, and tuned Apache and PHP memory limits to end a pattern of recurring site crashes.
- Consolidated two competing translation systems into a single Polylang setup managing **75 English/French translation pairs**; site audit errors dropped from **449 to 0**.
- Moved transactional email to Brevo with proper SPF/DKIM/DMARC, and set up automated nightly database backups to off-server object storage with 30-day retention.
- Oversaw migration of the hosting environment from AWS to DigitalOcean, simplifying infrastructure and improving stability.
